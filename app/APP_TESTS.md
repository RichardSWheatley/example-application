## Driver test coverage status

-- There are currently no dedicated in-repo unit test suites for per-driver
  tests inside this repository. If you want per-driver tests, add sample
  configurations under `samples/drivers/<driver>/` with `sample.yaml` and
  test sources in a `src/` directory.

## How to run a specific scenario locally

-- Build-only (fast):

```powershell
cd <app_name>
west build -b apollo510_mini samples/audio_utils -- "-DBOARD_ROOT=$PWD" "-DZEPHYR_EXTRA_MODULES=$PWD"
```

- Full run on device (if runnable and hardware attached):

```powershell
cd <app_name>
west build -b apollo510_mini samples/audio_processor -- "-DBOARD_ROOT=$PWD" "-DZEPHYR_EXTRA_MODULES=$PWD"
west flash
```
